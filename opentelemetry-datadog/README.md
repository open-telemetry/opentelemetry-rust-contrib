# OpenTelemetry Datadog — removed

`opentelemetry-datadog` has been removed from this repository after its deprecation in version 0.20.1, released on August 5, 2026. No further releases are planned.

Migrate to Datadog's first-party [`dd-trace-rs`](https://github.com/DataDog/dd-trace-rs) integration, built on top of `opentelemetry_sdk`.

Existing [crates.io releases](https://crates.io/crates/opentelemetry-datadog) remain available. The final release's [source and changelog](https://github.com/open-telemetry/opentelemetry-rust-contrib/tree/opentelemetry-datadog-0.20.1/opentelemetry-datadog) are preserved in its release tag.

See [#609](https://github.com/open-telemetry/opentelemetry-rust-contrib/issues/609) for the deprecation discussion and [#674](https://github.com/open-telemetry/opentelemetry-rust-contrib/issues/674) for the removal plan.
